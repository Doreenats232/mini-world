# MiniWorld
3D open-world sandbox with AI NPCs. Website + Android + Windows from one codebase.
- Play: https://doreenats232.github.io/mini-world/
- Developer notes (code layout, how to ship): see `CLAUDE.md`
- Commands: `npm test` (logic tests), `npm run build`, `GH_TOKEN=... npm run deploy -- "message"`
